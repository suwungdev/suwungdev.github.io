About suwung.id

A small space for building things.

Suwung.id is an independent digital space created to collect projects, experiments, and notes from the process of making them. The goal is not to publish as much as possible, but to document useful work clearly and honestly.

What is Suwung?

The word “suwung” is used here as a metaphor for an open space: a place where an idea can start small, change direction, and eventually become something useful. The website is deliberately minimal so the projects remain the focus.

What you will find here

The site currently features AIODL, the first public project under the suwung.id name. Future additions may include small browser tools, technical notes, experiments, and other original projects.

How projects are built

Projects are developed incrementally. I prefer lightweight interfaces, understandable code, and practical features over unnecessary complexity. Source code is shared when a project is intended to be open source.

This website is a project portfolio and documentation space. It does not claim to represent Google, GitHub, or any third-party service.
